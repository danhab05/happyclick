# Sources du projet utilisées sur l'accueil (lecture le 17 novembre 2026)

Demande de Dan : « Les quiz c'était en plus, c'était pas le truc principal. Faut quand même parler du projet. Regarde […] l'année dernière, […] le site officiel ». Pages publiques lues en GET, sans rien modifier.

- **happy-click.fr** (site officiel, campagne 2025-2026) : contenu identique à `source-snapshot/`. Menu : Accueil, Le KIT, Guides, 2024-2025, Qu'est-ce qu'un GATE ?, Qui sommes-nous ?. Devise : « Le NUMÉRIQUE n'est pas mauvais ... Il suffit d'en faire BON USAGE ». Le bloc « Happy Click, qu'est-ce que c'est ? » existe dans le code mais est commenté : projet mené par des étudiants de première année de Télécom SudParis, dans le cadre du programme GATE® ; commandité par Loïc BERNABLE (diplômé 2000, directeur technique et co-fondateur de LOG). Le kit est présenté comme les « ressources essentielles pour les interventions dans les écoles et collèges ».
- **gate.wp.telecom-sudparis.eu/gate-projets/happy-click/** (édition 2024-2025) : catégorie Citoyenneté, **Prix exceptionnel**, 5 étudiants ; tuteur Dominique Chiaroni (Nokia Bell Labs) ; client LOG – Loïc Bernable. Slogan « Déclic malin pour un futur serein ». Objectifs : éduquer au numérique responsable, réaliser un test de numérico-dépendance, encourager un usage sain des écrans. Activités : test de numérico-dépendance, jeu de cartes (QCM), fiches « mission Profil numérique ». **370 élèves dans 5 établissements** (1 collège, 4 écoles).

Seuls ces faits publics sont repris ; les noms d'écoles et d'étudiants ne sont pas recopiés.
